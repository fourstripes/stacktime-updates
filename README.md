# StackTime updates

Public download and Sparkle update feed for StackTime, the Four Stripes menu-bar time tracker.

- **Download:** [Latest release](https://github.com/fourstripes/stacktime-updates/releases/latest) → `StackTime-<version>-universal.zip` (macOS 13+, Apple silicon and Intel).
- **Update feed:** `https://github.com/fourstripes/stacktime-updates/releases/latest/download/appcast.xml`. Every update is EdDSA-signed and the app verifies it before installing.

The app is ad-hoc signed, not notarised. On first open, use System Settings → Privacy & Security → **Open Anyway** (macOS 15+), or right-click → Open on macOS 13–14. Later updates install in the app.

This repo only holds release files. The source is private.
